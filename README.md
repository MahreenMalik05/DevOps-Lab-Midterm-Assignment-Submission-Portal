
# Assignment Submission Portal

A simple assignment submission portal built with Node.js and Express.

## Features

- Student name, registration number, assignment title, and URL.
- Required-field validation.
- HTTP and HTTPS URL validation.
- Display of saved submissions.
- Automated tests using Jest and Supertest.

## Requirements

- Node.js
- npm

## Installation

```bash
npm install
```

## Run the application

```bash
npm start
```

Open http://localhost:3000 in your browser.

## Run automated tests

```bash
npm test
```
